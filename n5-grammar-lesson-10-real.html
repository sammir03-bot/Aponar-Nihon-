あります・います + Location + Position Words

কোথায় কী আছে / কে আছে — ঘর, শহর, ক্লাসরুম বর্ণনা করা

✨ Detailed Grammar

সহজ ব্যাখ্যা + structure + example

প্রতিটি pattern আগে structure দেখে, তারপর example মুখে বলুন। Audio button চাপলে Japanese sentence শুনতে পারবেন।

N が あります
Inanimate
জড় বস্তু/গাছপালা/ঘটনা আছে বোঝাতে あります।
book, desk, tree, event — এগুলোতে あります।
[thing] が あります
机があります。
つくえ が あります。ৎসুকুয়ে গা আরিমাসু।
ডেস্ক আছে।
公園に木があります。
こうえん に き が あります。কোয়েন নি কি গা আরিমাসু।
পার্কে গাছ আছে।
N が います
Animate
মানুষ/প্রাণী আছে বোঝাতে います。
student, teacher, dog, cat — এগুলোতে います।
[person/animal] が います
教室に学生がいます。
きょうしつ に がくせい が います。কিয়োশিৎসু নি গাকুসেই গা ইমাসু।
ক্লাসরুমে ছাত্র আছে।
庭に犬がいます。
にわ に いぬ が います。নিওয়া নি ইনু গা ইমাসু।
বাগানে কুকুর আছে।
Place に N が あります / います
Location first
কোন জায়গায় কী/কে আছে — জায়গা আগে বললে に লাগে।
location + に = existence point।
[place] に [N] が あります/います
部屋にテレビがあります。
へや に てれび が あります。হেয়া নি তেরেবি গা আরিমাসু।
ঘরে টিভি আছে।
事務所にミラーさんがいます。
じむしょ に みらー さん が います。জিমুশো নি মিরা সান গা ইমাসু।
অফিসে মিলার-সান আছেন।
N は Place に あります / います
Topic first
কোন জিনিস/ব্যক্তি কোথায় আছে — N কে topic করলে は。
প্রশ্ন: Nはどこですか। উত্তর: Placeにあります/います।
[N] は [place] に あります/います
本は机の上にあります。
ほん は つくえ の うえ に あります。হোন ওয়া ৎসুকুয়ে নো উয়ে নি আরিমাসু।
বইটি ডেস্কের ওপর আছে।
先生は事務所にいます。
せんせい は じむしょ に います。সেনসেই ওয়া জিমুশো নি ইমাসু।
শিক্ষক অফিসে আছেন।
N1 の 上/下/前/後ろ/中/隣 に N2
Position
কিছুর উপর/নিচ/সামনে/পেছনে/ভিতরে/পাশে বোঝাতে の + position word।
机の上, いすの下, 駅の前।
[reference] の [position] に [thing/person]
机の上に本があります。
つくえ の うえ に ほん が あります。ৎসুকুয়ে নো উয়ে নি হোন গা আরিমাসু।
ডেস্কের ওপর বই আছে।
椅子の下に猫がいます。
いす の した に ねこ が います。ইসু নো শিতা নি নেকো গা ইমাসু।
চেয়ারের নিচে বিড়াল আছে।
駅の前に銀行があります。
えき の まえ に ぎんこう が あります。একি নো মায়ে নি গিনকো গা আরিমাসু।
স্টেশনের সামনে ব্যাংক আছে।
だれも いません / 何も ありません
Nobody / Nothing
Question word + も-এর সঙ্গে negative existence verb বসলে ‘কেউ নেই/কিছু নেই’ বোঝায়।
মানুষ/প্রাণী: だれもいません; বস্তু: 何もありません। Affirmative verb ব্যবহার করবেন না।
だれも いません。 / 何も ありません。
教室にだれもいません。
きょうしつ に だれ も いません。কিয়োশিৎসু নি দারে মো ইমাসেন।
ক্লাসরুমে কেউ নেই।
かばんの中に何もありません。
かばん の なか に なに も ありません。কাবান নো নাকা নি নানি মো আরিমাসেন।
ব্যাগের ভেতরে কিছু নেই।

へや に なに が あります か。হেয়া নি নানি গা আরিমাসু কা।
ঘরে কী আছে?
机とベッドがあります。
つくえ と べっど が あります。ৎসুকুয়ে তো বেদ্দো গা আরিমাসু।
ডেস্ক ও বিছানা আছে।
先生はどこにいますか。
せんせい は どこ に います か。সেনসেই ওয়া দোকো নি ইমাসু কা।
শিক্ষক কোথায় আছেন?
先生は事務所にいます。
せんせい は じむしょ に います。সেনসেই ওয়া জিমুশো নি ইমাসু।
শিক্ষক অফিসে আছেন।
本はどこにありますか。
ほん は どこ に あります か。হোন ওয়া দোকো নি আরিমাসু কা।
বই কোথায় আছে?

Common Mistakes

❌ 犬があります。
✅ 犬がいます。 — প্রাণী হলে います।
❌ 本は机の上であります。
✅ 本は机の上にあります。 — existence location = に।
❌ 机上に本があります。
✅ 机の上に本があります। — position word আগে の লাগে।
