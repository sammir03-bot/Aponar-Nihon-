অনলাইন

আপনার ব্যক্তিগত জাপানি টিউটর

AI দিয়ে বাংলায় জাপানি ভাষা শিখুন — ব্যাকরণ, কানজি, ফুরিগানা, অনুবাদ সবকিছু একসাথে। নিচের যেকোনো একটি প্রশ্ন দিয়ে শুরু করুন।

Gemini AI উত্তর দিচ্ছে। Password, API key বা সংবেদনশীল তথ্য লিখবেন না।

সেটিংস

Gemini 2.5 Flash নিরাপদ Cloudflare backend দিয়ে সংযুক্ত। API key কখনো browser-এ পাঠানো বা সংরক্ষণ করা হয় না।
প্রতি browser-এ দিনে সর্বোচ্চ ২০টি প্রশ্ন। Password, API key, passport বা ব্যক্তিগত সংবেদনশীল তথ্য পাঠাবেন না।
