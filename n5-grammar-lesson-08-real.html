✨ Detailed Grammar

সহজ ব্যাখ্যা + structure + example

প্রতিটি pattern আগে structure দেখে, তারপর example মুখে বলুন। Audio button চাপলে Japanese sentence শুনতে পারবেন।

N は い-adj です
い-adj
い-adjective সাধারণত い দিয়ে শেষ হয় এবং noun/person/place-এর quality বলে।
例: 新しい, 大きい, 小さい, 暑い, 寒い।
N は [い-adj] です
この車は新しいです。
この くるま は あたらしいです。কোনো কুরুমা ওয়া আতারাশিইদেসু।
এই গাড়িটি নতুন।
今日は暑いです。
きょう は あついです。কিয়ো ওয়া আৎসুইদেসু।
আজ গরম।
この部屋は大きいです。
この へや は おおきいです。কোনো হেয়া ওয়া ওওকিইদেসু।
এই ঘরটি বড়।
N は な-adj です
な-adj
な-adjective sentence শেষে です-এর আগে সরাসরি আসে; noun modify করলে な লাগে।
きれい, 静か, 便利, 元気।
N は [な-adj] です / [な-adj] な N
この町は静かです。
この まち は しずかです。কোনো মাচি ওয়া শিজুকাদেসু।
এই শহর শান্ত।
きれいな人です。
きれいな ひとです。কিরেইনা হিতোদেসু।
সুন্দর মানুষ।
便利なアプリです。
べんりな あぷりです。বেনরিনা আপুরিদেসু।
সুবিধাজনক অ্যাপ।
い-adj → くないです
Negative い
い-adjective negative করতে শেষের い বাদ দিয়ে くないです।
いい → よくないです — irregular।
新しい → 新しくないです
この本は高くないです。
この ほん は たかくないです。কোনো হোন ওয়া তাকাকুনাইদেসু।
এই বই দামি নয়।
今日は寒くないです。
きょう は さむくないです。কিয়ো ওয়া সামুকুনাইদেসু।
আজ ঠান্ডা নয়।
な-adj / noun → じゃありません
Negative な
な-adjective ও noun negative করতে じゃありません/ではありません।
polite formal হলে ではありません।
静かです → 静かじゃありません
この町は静かじゃありません。
この まち は しずか じゃありません。কোনো মাচি ওয়া শিজুকা জা আরিমাসেন।
এই শহর শান্ত নয়।
あの人は元気じゃありません。
あの ひと は げんき じゃありません。আনো হিতো ওয়া গেনকি জা আরিমাসেন।
ওই ব্যক্তি সুস্থ/উদ্যমী নয়।
とても + affirmative / あまり + negative
Degree
とても = খুব; あまり = খুব একটা না (negative এর সাথে)।
あまり いいです ❌; あまり よくないです ✅
とても高いです / あまり高くないです
東京はとても便利です。
とうきょう は とても べんりです。তোকিয়ো ওয়া তোতেমো বেনরিদেসু।
টোকিও খুব সুবিধাজনক।
この映画はあまりおもしろくないです。
この えいが は あまり おもしろくないです。কোনো এইগা ওয়া আমারি ওমোশিরোকুনাইদেসু।
এই সিনেমা খুব একটা মজার নয়।
N は どうですか / どんな N ですか
Impression / Type
どうですか দিয়ে কোনো জানা বিষয় কেমন তা জানতে চাওয়া হয়। どんな + noun দিয়ে কী ধরনের ব্যক্তি/স্থান/বস্তু জানতে চাওয়া হয়।
どんな সবসময় noun-এর আগে বসে; どう-এর পরে সরাসরি ですか আসে।
N は どうですか。 / N1 は どんな N2 ですか。
日本の生活はどうですか。
にほん の せいかつ は どうです か。নিহোন নো সেইকাৎসু ওয়া দোদেসু কা।
জাপানের জীবন কেমন?
奈良はどんな町ですか。
なら は どんな まちです か。নারা ওয়া দোন্না মাচিদেসু কা।
নারা কী ধরনের শহর?
古い町です。
ふるい まちです。ফুরুই মাচিদেসু।
পুরোনো শহর।

日本語はどうですか。
にほんご は どうです か。নিহোনগো ওয়া দোদেসু কা।
জাপানি কেমন?
おもしろいですが、難しいです。
おもしろいです が、 むずかしいです。ওমোশিরোইদেসু গা, মুজুকাশিইদেসু।
মজার, কিন্তু কঠিন।
あなたの町は静かですか。
あなた の まち は しずかです か。আনাতা নো মাচি ওয়া শিজুকাদেসু কা।
আপনার শহর শান্ত?
はい、とても静かです。
はい、 とても しずかです。হাই, তোতেমো শিজুকাদেসু।
হ্যাঁ, খুব শান্ত।
この料理はどうですか。
この りょうり は どうです か。কোনো রিয়োরি ওয়া দোদেসু কা।
এই রান্না কেমন?

Common Mistakes

❌ きれい人
✅ きれいな人 — な-adj noun-এর আগে হলে な লাগে।
❌ 高いじゃありません
✅ 高くないです — い-adj negative = くないです।
❌ あまりおいしいです
✅ あまりおいしくないです — あまり সাধারণত negative।
